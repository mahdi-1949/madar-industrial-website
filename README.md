# مدار | نمونه‌کار وب‌سایت صنعتی

نمونه‌کار فارسی و راست‌چین برای معرفی تجهیزات آزمایشگاهی و فرآوری مواد معدنی. طراحی واکنش‌گرا برای موبایل و دسکتاپ.

- بیش از ۳۰ صفحه: کاتالوگ، صفحه جزئیات هشت تجهیز، راهکارها، خدمات، پروژه‌های نمونه و دانش‌نامه
- جست‌وجو و فیلتر محصولات، مقایسه تا سه دستگاه و فهرست درخواست استعلام
- فرم درخواست با خروجی قابل دانلود، سه راهنمای قابل چاپ و صفحه حریم خصوصی
- قلم فارسی و عکس‌های موضوعی محلی؛ بدون وابستگی JavaScript به CDN

## مشاهده محلی

در ریشه مخزن اجرا کنید:

```sh
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## انتشار با GitHub Pages

از **Settings → Pages**، شاخه `main` و پوشه `/ (root)` را به‌عنوان منبع انتشار انتخاب کنید. این نسخه برای دامنه ریشه وب‌سایت طراحی شده است؛ اگر از نشانی پروژه‌ای با مسیر `/madar-industrial-website/` استفاده می‌کنید، مسیرهای ریشه‌ای دارایی‌ها باید برای آن تنظیم شوند.

مدار، نامی فرضی برای نمایش نمونه‌کار است. پروژه‌ها و تصاویر تجهیزات مستند واقعی شرکت نیستند؛ نمودار تجهیزات شماتیک است. فرم درخواست در این نسخه اطلاعات را به جایی ارسال نمی‌کند و یک فایل محلی برای دانلود می‌سازد. پیش از استفاده تجاری، اطلاعات شرکت، محصولات، تماس و اتصال فرم‌ها را جایگزین و تکمیل کنید.

## حقوق دارایی‌ها

منابع عکس و محتوای نمایشی در صفحه «درباره تصاویر» آمده‌اند. فایل مجوز قلم Vazirmatn نیز در پوشه `assets` قرار دارد.
